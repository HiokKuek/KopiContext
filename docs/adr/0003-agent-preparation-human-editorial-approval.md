# Require editorial approval for all publishing

Agents may process Source Submissions, propose Topic or Subtopic placement, extract Claims, and draft Briefings or Current Updates. They may not create accepted Sources, alter taxonomy without review, publish, merge code, or deploy; the sole editor explicitly approves published content and the project owner reviews code changes.

## Considered Options

- Autonomous agent publishing and delivery
- Agent preparation with human approval gates

## Consequences

Every generated output needs provenance and a review state, which makes high-risk civic content auditable and keeps the product's source-backed promise credible.
